# Changelog

## 0.1.0 — Experimental source release

- Local chat and code assistance with an allow-listed GGUF model catalog.
- ComfyUI image generation, FLUX.2 Klein editing and persistent image jobs.
- Optional audio runtimes and experimental Krita integration.
- React/TypeScript frontend, FastAPI backend and SQLite persistence.
- User-relative configurable paths, local setup script and example configuration.
- Backend/frontend checks in GitHub Actions; local models and private runtime data excluded from source control.

This is a Linux desktop prototype, originally exercised on AMD hardware. Other systems require their own engine and hardware validation. Earlier machine-specific development notes are not part of the source release.
