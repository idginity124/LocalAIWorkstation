# Local AI Workstation v0.1.0

First experimental source release for a local Linux AI workspace.

## Included

- Streaming chat and code assistance with saved conversations and approved file edits.
- ComfyUI image generation, FLUX.2 Klein editing and persistent image jobs.
- Optional audio engines and experimental Krita editing.
- Turkish/English documentation, 11 interface languages, setup script and configurable local paths.
- GitHub Actions checks and a fix for folder-picker tests on machines without Zenity.

## Download and run

Download either `LocalAIWorkstation-v0.1.0-source.zip` or `LocalAIWorkstation-v0.1.0-source.tar.gz`, then extract it. These are source packages, not standalone installers. `SHA256SUMS` contains their checksums.

Requires Linux, Python 3.12–3.14 and Node.js 22+:

```bash
cd LocalAIWorkstation-v0.1.0
bash setup.sh
cp .env.example .env
# Adjust paths in .env if needed.
bash start.sh
```

Open http://127.0.0.1:8000. Application setup downloads dependencies. Inference engines and model weights must be installed separately; they are not bundled. Chat uses a managed `llama-server`, not an LM Studio/Ollama API connection. See `docs/INSTALLATION.md` in the package.

## Validation and limits

- Locally verified: 155 backend tests, 11 utility tests, frontend build and 13 frontend/language checks. These results do not establish GitHub Actions status for this release.
- Originally exercised on CachyOS with AMD RX 6800 XT; other hardware and operating systems are not validated targets.
- Real GPU generation, a fresh online dependency installation and browser end-to-end checks were not repeated for this release.
- Audio/Krita need additional setup; video generation is not implemented.
- Single-user local application: do not expose the API publicly.

MIT-licensed application code. Models and third-party engines retain their own terms. Personal recordings, conversations, models, caches and runtime reports are excluded.
