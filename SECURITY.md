# Security

This application is designed for a single user's Linux desktop and binds to `127.0.0.1`. It has no multi-user authentication and must not be exposed to the internet or placed behind a public proxy without a separate security review.

See [the security model](docs/SECURITY.md) for local API and file-access boundaries. Use GitHub's private vulnerability reporting if enabled; otherwise contact the repository owner privately. Do not post credentials, conversations, voice recordings or exploit details in a public issue.
